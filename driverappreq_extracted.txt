
Vehicle Provider / Driver App – Complete Requirements
1. Provider Types
The provider app should support 3 types of providers:

A. Driver
A person who drives a vehicle owned by someone else.
Example:
Driver Rahul → drives vehicle owned by Fleet Owner Amit.

B. Fleet Owner
A person/company that owns one or multiple vehicles and may have multiple drivers.
Example:
Amit owns 10 cars → assigns different drivers to each car.

C. Driver + Fleet Owner
A person who owns the vehicle and also drives it.
Example:
Rahul owns 1 car → Rahul himself drives it.
During registration, the provider selects:
Provider Type
Driver 
Fleet Owner 
Driver + Fleet Owner

8. Payment Visibility
This should be enforced at the backend/API level, not just hidden from the UI.
For example:
Fleet Owner API
GET /fleet/trips
GET /fleet/earnings
GET /fleet/payments
GET /fleet/reports
Driver API
GET /driver/current-trip
GET /driver/assigned-vehicle
GET /driver/new-trips
Don't send payment data in the driver API response at all.
For example, don't do this:
{
  "tripId": "TR123",
  "pickup": "Patna Junction",
  "drop": "Airport",
  "fare": 450,
  "commission": 45,
  "fleetEarning": 405
}
Instead:
{
  "tripId": "TR123",
  "pickup": "Patna Junction",
  "drop": "Airport",
  "status": "ASSIGNED"
}
This is much safer.
